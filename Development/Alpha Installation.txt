Hello! This file is for installing the BZ Randomizer during its Alpha release.

# Python Installation

Step 1: Install Python from https://www.python.org/
Preferably download Python 3.10 or newer versions, 64-bit recommended.

Step 2: During Installation, select 'Add Python to PATH' to allow commands to the Terminal.

Verification: To verify if Python has properly installed, run the following command:
"python --version" or "python3 --version"

# Command Prompt

Step 3: Open up the Command Prompt
Windows: Press Win + R, Type 'cmd' and press Enter.
Linux: Ctrl + Alt + T              
~~MacOS: Command + Space, type "Terminal"~~ [NOT supported as of now!]

# Upgrade Pip (Python's Packet Manager)

Step 4: Type: "python -m pip install --upgrade pip"
If that fails, input "python3 -m pip install --upgrade pip"
(This ensures you have the latest version of pip to avoid errors, and -m avoids issues with the PATH.)

# Dependencies Install

Step 5: Install Pillow (Required to create the UI) type: 
"python -m pip install pillow"

Step 6: Verify Tkinter type:
python -c "import tkinter; print(tkinter.TkVersion)"


# Run the .exe

The .exe for the application is inside Blast-Zone-Randomizer-main\Blast-Zone-Randomizer-main\dist\
under Main_UI.
