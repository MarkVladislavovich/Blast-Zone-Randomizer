Hello! This file is for installing the BZ Randomizer during its Alpha release.

# Python Installation

Step 1: Install Python from https://www.python.org/
Preferably download Python 3.10 or newer versions, 64-bit recommended.

Step 2: During Installation, select 'Add Python to PATH' to allow commands to the Terminal, then restart the terminal.

Verification: To verify if Python has properly installed, run the following command:
"python --version" or "python3 --version"

# Run the .exe

Tkinter and Pillow should be packaged in with the exe. So to launch the .exe for the application is inside Blast-Zone-Randomizer-main\Blast-Zone-Randomizer-main\dist\
under Main_UI.
